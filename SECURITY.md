# Security Policy

## Supported Versions

Only the latest release of this is ever considered supported.  
Support is provided only on a best-effort basis, and no guarantees are offered.

## Reporting a Vulnerability

1. Under the repository name, click the `Security` tab. If you cannot see the "Security" tab, select the  dropdown menu, and then click `Security`.
1. Click `Report a vulnerability` to open the advisory form.
1. Fill in the advisory details form.
